# MESAFARTAI - Logística e Inteligência Assistiva no Combate à Fome

![Logo](assets/logo_mesafartai.png)

## Descrição

O MESAFARTAI é um chatbot feito em Python que ajuda a conectar quem tem alimento sobrando (mercados, restaurantes, feirantes) com ONGs que precisam de doação.

O doador manda uma mensagem no chat, o sistema identifica o que ele quer, pega as informações do alimento (tipo, quantidade e validade) e usa KNN para encontrar a ONG mais próxima para fazer a coleta.

## Alinhamento com a ODS 2

O projeto está ligado à ODS 2 da ONU (Fome Zero e Agricultura Sustentável), porque ajuda a levar alimentos que seriam desperdiçados para pessoas em situação de vulnerabilidade.
