MESAFARTAI - Etapa 1 (06/10)

O que foi pedido na etapa 1:

1. Formar um grupo de 3 a 5 alunos e criar um repositório público no GitHub
   chamado PROJETO-MESAFARTAI, adicionando os integrantes e o professor.

2. Criar o README.md com o título do projeto, uma descrição da solução,
   o alinhamento com a ODS 2 e o nome e RA dos integrantes.
   Criar a pasta docs com o regras.txt e o escopo_projeto.md.

3. Criar um logo com IA que junte alimento/acolhimento com tecnologia,
   salvar em assets/logo_mesafartai.png e colocar o prompt no escopo_projeto.md.

4. Criar o src/database.py que cria o banco SQLite (mesafartai.db) com as
   tabelas usuarios, doacoes e matches, e insere dados de teste.

5. Enviar e-mail para o professor com os integrantes e o link do repositório.
